IDEIAS PARA APERFEICOAR O APP (passe para o Claude Desktop melhorar)
====================================================================

1. INTERFACE VISUAL (tela bonita, profissional)
   - Fundo escuro (#0B0E14), cards dourados (#F0B90B)
   - Mostrar moeda selecionada grande no topo
   - Barras de preço coloridas (verde = alta, vermelho = baixa)
   - Card com RSI (mostre % e cor: verde se 30-70, vermelho se >70 ou <30)
   - Card com MACD (numero + seta para cima/baixo)
   - Card de SINAL grande: "ENTRAR AGORA" ou "AGUARDE" — cor diferente

2. SELECAO DE MOEDA MAIS FACIL
   - Botao para digitar: PETR4, VALE3, XAUUSD, EURUSD, USDJPY, BTC-USD
   - Lista de favoritos salvos no banco (para trocar rapido)
   - Quando trocar, a tela atualiza imediatamente (nao precisa fechar)

3. ANALISE CONTINUA MELHORADA
   - A cada 15 minutos (ou 5 min se usuario quiser) gera novo sinal
   - Mostre "Ultima analise: 14:32" — para saber se esta atualizado
   - Se o preço mudou muito, avise: "Preco mudou +2% desde ultima analise"
   - Guarde historico no SQLite (para consultar depois: "Como estava 2h atras?")

4. PREVISAO MAIS CLARA
   - Se RSI < 30 + MACD > 0 = "Provavelmente sobe em breve"
   - Se RSI > 70 + MACD < 0 = "Provavelmente desce em breve"
   - Se MM9 > MM21 + MACD > sinal = "Tendencia alta confirmada"
   - Se MM9 < MM21 + MACD < sinal = "Tendencia baixa confirmada"
   - Diga diretamente: "NAO OPERE AGORA — aguarde confirmacao"
   - Ou: "ENTRE — momento favoravel"

5. ALERTAS VISUAIS (se quiser notificacao)
   - Quando aparecer sinal de ENTRAR: popup verde ou piscada
   - Quando aparecer SAIR: popup vermelho
   - Quando trocar de moeda: mostrar "Agora monitorando: XAUUSD"
   - Se perder 3%: alerta urgente "STOP LOSS — SAIA"

6. EXPLICACAO PARA NAO-TRADER (muito importante)
   - Cada numero vem com explicacao: "RSI 45 = neutro, nem muito caro nem muito barato"
   - Se RSI 75 = "Muito caro — pode cair"
   - Se RSI 20 = "Muito barato — pode subir"
   - Se MACD +0.12 = "Subindo — tendencia alta"
   - Se MACD -0.05 = "Descendo — tendencia baixa"
   - Sempre mostre: "ISSO NAO PREVE. USE STOP LOSS."

7. MODO "SIMPLE vs PRO"
   - Simple: mostra apenas "COMPRA / AGUARDAR / VENDER" + explicacao 1 linha
   - Pro: mostra todos os numeros (RSI, MACD, medias, bandas, ATR)

8. ARQUIVOS QUE PODEM SER ADICIONADOS
   - HTML do dashboard (APP_TRADER_PROFISSIONAL.html) como referencia visual
   - Prompt completo (PROMPT_CLAUDE_DESKTOP.md) como guia
   - Codigo fonte (codigo_app_trader.py) como base

9. OUTRAS MELHORIAS
   - Adicionar ATR (volatilidade) — se ATR alto = risco alto
   - Digitar moeda no teclado (nao precisa de menu complexo)
   - Exportar relatorio simples (texto) — "Hoje PETR4 subiu, sinal mudou"
   - Turma de favoritos: PETR4, ITUB4, VALE3, XAUUSD, EURUSD
